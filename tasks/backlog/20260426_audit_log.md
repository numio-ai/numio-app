# Audit log of authentication and admin actions

## Problem statement

Phase 1 records nothing. Cloud-hosted deployments will need authentication and admin-action records for security and incident review.

## Scope

In scope:
- `audit_events` table.
- Instrument: login success / failure, logout, user create / disable / enable / role-change, AWS account connect / disconnect.
- `Settings → Audit` page with list and filter.
- Default 90-day retention, configurable.

Out of scope:
- External SIEM forwarding.

## Acceptance criteria

- Every event type lands a row.
- Admin can list and filter events by actor, target, type, time.
- Retention is enforced by a periodic job.

## Quality gates

- Tests verify event coverage for every instrumented call site.
- Performance test on a year of synthetic data confirms acceptable list latency.
