# Persist Policies CRUD + bulk update + open-violations count

## Problem statement

`api/ia_v2_policies.py` seeds 7 policies into a module-level dict. The frontend `PoliciesPage` consumes `INITIAL_POLICIES` directly. Real implementation needs (a) a `policies` table, (b) integration with the compliance engine to surface real `open_violations` counts, and (c) the page calling the API.

## Scope

In scope:
- Alembic migration: `policies(id, workspace_id, name, description, type, mode, enabled, scope, created_at, updated_at)`. Use `policy_violations` table (new or existing) to source the open count.
- SQLAlchemy model + `PolicyRepository`.
- Implement endpoints: `GET /policies` (with `open_violations_total` aggregate), `POST`, `PATCH`, `DELETE`, `POST /policies/bulk` with full partial-failure semantics.
- Real `open_violations` count per policy: `SELECT COUNT(*) FROM policy_violations WHERE policy_id = ?`. If `policy_violations` doesn't exist yet, create it in this migration (no rows seeded; surfaces 0 until the compliance engine writes rows).
- AuthZ: workspace-scoped; admins write; readers read.
- Frontend: `PoliciesPage` deletes its `INITIAL_POLICIES` array and uses the live endpoints.

Out of scope:
- Real policy authoring (DSL editor) — `+ New policy` remains a stub.
- Real Change-Mode confirmation dialog — stub button in the bulk bar.
- Policy enforcement / triggering — out of IA v2 scope.

## Acceptance criteria

A1. Alembic migration applies; `policies` and `policy_violations` tables exist.

A2. `GET /policies` returns rows with accurate `open_violations` counts (0 when no violations seeded).

A3. Bulk endpoint enforces partial failure: if 5 of 7 ids exist, returns `accepted=5, rejected=2, errors=[...]`.

A4. Pytest covers all five endpoints + partial-failure bulk + violations-count aggregation.

A5. Frontend `PoliciesPage` no longer imports `INITIAL_POLICIES`; renders live data.

## Quality gates

- Backend pytest passes.
- Frontend `npm test` + `npm run build` pass.
- `git grep -F 'INITIAL_POLICIES' frontend/src/pages/Policies/` returns zero hits.
