# IA v2 sidebar — 4 labeled collapsible groups, Inbox badge

# IA v2 sidebar — 4 labeled collapsible groups, Inbox badge

## Problem statement

`OverviewSidebar.jsx` renders a 5-group flat sidebar with names that don't match what users are trying to do — "Usage & Cost > Alerts" links to `/feed`, "Optimize" holds resource lists, "Configure" mixes governance with settings. Each parent expands a sub-tree, doubling the cognitive load. The Inbox (today: Feed) is buried mid-list with no urgency signal.

## Scope

In scope:
- Build a new sidebar matching `docs/design-mocks/numio-ia-v2/project/numio-shell-v2.jsx` lines 149–294.
- Four labeled groups (UNDERSTAND, OPTIMIZE, GOVERN) plus an unlabeled top group with Inbox and an unlabeled bottom admin group.
- Click on a group label toggles collapse. State is local to the session (not persisted).
- Group containing the active route is expanded on first render regardless of saved collapse state.
- Inbox row carries a red unread-count badge fed by a hook (`useInboxUnreadCount`); the hook itself is supplied by task `ia_v2_inbox`. Badge is hidden when count is 0.
- Use the existing lucide-style icon set (the v2 mock uses lucide subset; map each entry to the closest existing icon in the codebase).

Out of scope:
- Mobile sidebar (`MobileMenu.jsx`) — separate UX; cleaned up only to remove deleted-route references in task `ia_v2_routes`.
- Top bar — task `ia_v2_topbar`.
- Removing legacy routes — task `ia_v2_routes`.

## Acceptance criteria

A1. Sidebar items, in order: `Inbox` · group label `UNDERSTAND` {Usage, Resources} · group label `OPTIMIZE` {Recommendations, Autopilot} · group label `GOVERN` {Tag Governance, Budgets, Policies} · {Data Ingestion, Data Explorer, Settings}.

A2. Each group label is a click target. Clicking toggles its child list. The group containing the current route is expanded on first render.

A3. The Inbox row shows a small red circular badge containing the unread count from `useInboxUnreadCount()`. Badge hidden when count = 0.

A4. The active item has a subtle background highlight matching the v2 mock (`#f3f4f6`); non-active items have transparent background.

A5. Every entry has a meaningful lucide icon — no placeholder squares or default circles.

A6. Unit test renders the sidebar at each top-level IA v2 route (`/inbox`, `/usage`, `/resources`, `/recommendations`, `/autopilot`, `/tag-governance`, `/budgets`, `/policies`, `/ingestion`, `/data-explorer`, `/settings`) and asserts the corresponding item is highlighted and its parent group is expanded.
