# Rename audit_events to audit_config_events

## Problem statement

Numio's single audit table `audit_events` records configuration changes (account registrations, policy CRUD, threshold edits). Feature `tag_management` introduces a second audit stream for actions taken against external systems (tag writes). To keep the two streams queryable independently, the config stream must be renamed first. Spec §5.1 and §11 step 1+3.

## Scope

In scope:
- Alembic revision (M1, spec §11 step 1): `op.rename_table('audit_events','audit_config_events')`; rename indexes `ix_audit_events_*` → `ix_audit_config_events_*`. Reversible downgrade.
- Rename model `AuditEvent` → `AuditConfigEvent`, repository `AuditEventRepository` → `AuditConfigEventRepository`, schemas `AuditEvent*Response` → `AuditConfigEvent*Response`.
- Rebind the `@audit_trail` decorator internally to the renamed entity (signature unchanged).
- Rename API route `/api/v1/audit-events` → `/api/v1/audit-config-events`. No alias, no redirect.
- Update all `@audit_trail`-decorated call sites (~10) and backend tests.
- Docs: update any reference to the old table/route name.

Out of scope:
- New action-event tables (task `audit_action_events_schema`).
- Frontend audit page (task `audit_page_split`, which must land in the same release per spec §11 step 3+4).

## Acceptance criteria

A1 (=feature A8). `/api/v1/audit-config-events` returns the same shape and data `/api/v1/audit-events` returned before the rename. `/api/v1/audit-events` returns HTTP 404.
A2. All `@audit_trail`-decorated endpoints continue to write audit rows under `audit_config_events`.
A3. Alembic upgrade then downgrade round-trips cleanly on a populated table (no data loss, indexes restored).

## Quality gates

- `cd backend && uv run pytest` green; tests updated for the renamed entity/route.
- `cd backend && uv run ruff check .` clean.
- `git grep -n "audit_events\|audit-events\|AuditEventRepository\|class AuditEvent\b" backend/` returns zero hits outside the migration's downgrade.
- Alembic upgrade/downgrade verified against this worktree's Postgres.
- Must ship together with `audit_page_split` (spec §11).
