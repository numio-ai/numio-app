# IA v2 Usage page — unified Cloud + AI, tag-as-dimension, saved views

## Problem statement

`CloudUsagePage` and `AIUsagePage` are structural duplicates with hard-coded filter dimensions. Period labels drift (top says 30D, breakdown says MTD). Tags aren't first-class — the most important slicing dimension for FinOps users. Users cannot save or share a view.

## Scope

In scope:
- One page at `/usage` with Cloud and AI tabs; tab selection persists in URL (`?scope=cloud|ai`).
- Group-by selector with two labeled sections: Platform (Service, Account, Region, Provider, Resource type) and Tags (every tag key in the schema). Default Cloud → `cost-center`; default AI → `team`.
- Filter chips supporting platform AND tag attributes; tag chips visually distinct (indigo tint, `tag:` prefix); inline `✕` to remove.
- Untagged-spend callout above chart: shown when "Untagged" sum > 0 for the active group-by; links to Tag Governance via "Fix in Tag Governance →".
- Range selector drives all dependent labels: chart card title, delta caption ("vs previous {N} days"), breakdown table header.
- Saved views: dropdown picker with active checkmark, owner attribution, per-row copy-link, ⋯ menu (rename / set default / delete), + Save current, Manage all views… link. URL serializes range + group-by + filters + active view id.
- Inline "Manage tag schema →" link adjacent to the dimension counter; navigates to Tag Governance Schema tab.
- Chart legend, table header, KPIs reflect active group-by.
- KPI strip above the chart is removed per chat 2026-05-16; "Spend over time · {range} · by {dim}" / "$total" / "↑↓ delta vs prior" / "Forecast EOM ${forecast}" sit inline in the chart card header.

Out of scope:
- Sub-group / split-by.
- Compare mode ("vs last 30d" overlay).
- Open-state picker designs for Group-by and Filter pickers (deferred per chat 2026-05-16).
- Backend persistence of saved views — `ia_v2_be_saved_views`.

## Acceptance criteria

A1. `/usage` renders Cloud tab by default. Switching to AI tab updates URL with `?scope=ai`.

A2. Group-by picker is sectioned: Platform · Tags. Selecting a tag dimension prefixes the chip with `tag:`.

A3. Selecting a range (e.g. 30D) updates within the same render cycle: chart card title to "Spend over time · last 30 days · by tag:{dim}", delta caption to "vs previous 30 days", breakdown table label to "Breakdown by tag · {dim} · last 30 days". No combination of inputs produces a mismatched label.

A4. Adding a filter chip refines chart and table without page reload.

A5. Untagged callout: when sum > 0, a single-line yellow callout appears above the chart with the amount and "Fix in Tag Governance →" link. When sum = 0, callout is hidden.

A6. Saved views: clicking View picker opens the list; selecting a view writes its parameters to the URL. Clicking the link icon on a row copies the URL to clipboard.

A7. Copying the URL and opening it in a new tab restores the same view (mock-store-backed for now).

A8. KPI strip removed; chart card header carries the inline meta block.

### Notable decisions or deviations

- **Filter chips: serialized as repeated `f=kind:key:value1,value2` URL params**, not as a JSON blob. Easier to inspect in the address bar and survives copy/paste cleanly. Multi-value support is implicit via comma-split.
- **GroupBy default per scope** is resolved by `useUsageUrlState` when the URL omits `groupBy` — Cloud falls back to `tag:cost-center`, AI to `tag:team` (per A2 / scope's `defaultGroupBy`). Explicit `?groupBy=...` overrides.
- **Saved views write through both `view` and the view's preset (`groupBy`, `filters`) to URL** so that copy-link captures the full state, not just the view id. This satisfies A7 (URL round-trip) even if the saved-view store changes later.
- **`+ Filter` / `Save as…` / `Export CSV` / `Manage all views…` rendered but inactive** — out of scope (open-state picker designs deferred per chat 2026-05-16). Buttons are visible to match the mock; clicking is a no-op.
- **Granularity selector is decorative** — only "Daily" rendered. Multi-granularity is out of scope for the IA v2 first cut.
- **Chart is a hand-rolled SVG stacked area** (ported from mock), not Recharts — Recharts is already a 338kb chunk; this is a one-page mock-data render where the SVG is simpler and matches the mock's style.
- **Forecast pill shows for Cloud only** (AI scenario has `forecast: null`) — matches mock.
- **No clipboard error toast** if `navigator.clipboard.writeText` fails — silently swallows. Acceptable for mock; backend task will add proper feedback later.
- **Test count: 248 → 260** (+12 UsagePage tests).
