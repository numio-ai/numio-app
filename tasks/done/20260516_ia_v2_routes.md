# IA v2 route cleanup — default to /inbox, delete legacy routes, sweep in-app references

## Problem statement

`App.jsx` currently registers ~50 routes covering the legacy IA. IA v2 removes large swathes of those URL paths. Many in-app links, headers, mobile menus, and `Navigate` redirects still point at these paths. Per user call on 2026-05-16, old external URLs should not get redirects — they should 404. But in-app navigation must never produce a 404.
