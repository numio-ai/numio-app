# IA v2 top bar — drop Customize, merge Data + Autopilot into System pill

## Problem statement

`SlimTopBar.jsx` exposes 8 controls on the right edge — Ask Numio, Chat, Customize Dashboard, Theme, Bell, Role, Data status pill, Autopilot pill. Two of them carry overlapping information (data sync state, autopilot enabled) that the user only needs as one summary. Customize Dashboard applies only to Overview but appears on every page. The result: a busy top bar that interrupts page-level focus.

## Scope

In scope:
- Remove the Customize Dashboard button from `SlimTopBar.jsx` and from anywhere else it renders.
- Replace `DataStatusPill` and any inline Autopilot pill with a single "System" pill — green when both upstream signals are green, amber when one is degraded, red when one has failed.
- Clicking System opens a popover showing both: data-sync status (last sync time, success/fail, "View ingestion →" link) and Autopilot status (active rule count, paused-all state, "Open Autopilot →" link).
- Keep Ask Numio, Chat toggle, Theme, Bell, Role badge.

Out of scope:
- Mobile top bar — separate redesign.
- Replacement for Customize-Dashboard functionality (Overview is being deleted; no replacement needed).
- Notification panel redesign (`Bell`) — keep current implementation.

## Acceptance criteria

A1. Top bar renders exactly six controls right of the breadcrumb, in order: Ask Numio (sparkles), Chat toggle, Theme, Bell, Role badge, System pill.

A2. System pill color mapping: `data_sync = ok AND (autopilot = ok OR autopilot = disabled)` → green; either signal `degraded` → amber; either signal `failed` → red.

A3. Hovering System pill shows tooltip with one-line summary ("Data synced 2m ago · Autopilot active" or analogous).

A4. Clicking System opens a popover with two stacked rows: data sync (timestamp, status text, "View ingestion →" navigates to `/ingestion`) and Autopilot (active rule count, paused-all state, "Open Autopilot →" navigates to `/autopilot`).

A5. `CustomizeDashboardDrawer.jsx`, `CustomizePanel.jsx`, and `DashboardPrefsContext.jsx` are deleted along with their imports and provider wiring in `App.jsx`. No regression in surviving pages.

A6. `DataStatusPill.jsx` (and any inline Autopilot pill) is deleted or refactored into the new System pill component.
