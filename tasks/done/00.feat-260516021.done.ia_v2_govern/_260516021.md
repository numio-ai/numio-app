# Numio IA v2 — Govern surfaces (Tag Governance, Budgets, Policies)

## Problem statement

Tag Governance today uses a heatmap that does not scale past ~30 resources, has an "Audit Log" tab that is a confusing deep link, and ships an in-page "Ask Numio" button that duplicates the global chat. Budgets and Policies are placed inside the legacy `/financial_planning` and `/govern` URL trees with stale toolbars (no saved views, no share-by-URL) and "Edit" buttons in lieu of toggles.

## Objective

The Govern section's three pages — Tag Governance, Budgets, Policies — share the same toolbar pattern as Usage and Resources (Views · Share · Save as · Refresh), drop colored banners in favor of subtitle signals, replace "Edit" with row toggles + `⋯` menus, and standardize bulk action bars. Tag Governance specifically replaces the heatmap with a dense resource × tag-key table that scales.

## Scope

In scope:
- Tag Governance redesign (drop heatmap, dense table, Resources + Schema tabs, bulk select, remove in-page Ask Numio, standard toolbar).
- Budgets redesign (cards with pacing tick, standard toolbar).
- Policies redesign (toggle column, mode chips, bulk actions, standard toolbar).

Out of scope:
- Activity / audit log surface — leave a link to the existing audit page.
- Suggest-with-Numio chat-prefill flow — button visible, no chat wiring.
- Budget creation wizard — `+ New budget` opens a stub.
- Policy authoring — `+ New policy` opens a stub.
- Backend persistence — `ia_v2_be_budgets`, `ia_v2_be_policies`.
- Tag write-back to AWS — handled separately in `tasks/features/20260515_tag_management.md`.

## Acceptance criteria

A1. All three pages have the standard toolbar (View picker, Share link, Save as…) and dense rows.

A2. Tag Governance has only two tabs: Resources (default) and Tag schema. No "Audit log" tab. A small "Activity →" link in the toolbar replaces it.

A3. Tag Governance Resources tab shows a dense table — each row is a resource, each required tag is a column, cells are colored chips (green=ok, orange=drift, red=missing required, gray=missing optional). No heatmap.

A4. Tag Governance does not render an in-page "Ask Numio" button. The global top-bar Ask Numio is the only entry point.

A5. Tag Governance supports bulk select with an action bar: Apply tag · Suggest with Numio · Bulk rename value · Export.

A6. Budgets cards show a pacing tick on the burn-down bar at the expected-day position and an "Expected at day N: X% · ±Ypp ahead/behind" annotation. Banner is gone; signals fold into subtitle.

A7. Policies table has an Enabled toggle column + a Mode chip (Block / Warn / Auto-remediate). "Edit" buttons are removed; row controls are toggle + `⋯` menu. Bulk action bar: Enable · Disable · Change mode · Export.

A8. Budgets is at `/budgets`. Policies is at `/policies`. Tag Governance stays at `/tag-governance`. Legacy paths (`/financial_planning/budgets`, `/govern/policies`) are removed in `ia_v2_routes`.
